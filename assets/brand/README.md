# Teloa brand companion / Teloa 品牌伙伴

`teloa-reading.webp` is the approved Teloa squirrel reading artwork, reused unchanged from [Teloa's public brand assets](https://www.teloa.ai/brand/reading.webp). The README displays it at 120 × 120 pixels as a compact brand mark. It is not an architecture diagram, evidence of execution or a certification mark.

The Teloa name, brand graphics and squirrel artwork remain subject to their [separate brand-use terms](https://www.teloa.ai/brand-kit/). The repository's Apache-2.0 license does not grant trademark or brand-artwork usage rights.

Teloa 名称、品牌图形与小松鼠素材遵循[独立品牌使用规则](https://www.teloa.ai/brand-kit/)。仓库的 Apache-2.0 许可不授予商标或品牌图形使用权。
