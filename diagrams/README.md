# AI Worker Standard 1.0 diagrams

The [Chinese guide](../docs/guide.zh-CN.md) and [English guide](../docs/guide.en.md) use four explanatory diagrams: product-to-standard mapping and components, organizational composition, technical architecture and delivery workflow.

**AI employee is Teloa’s product concept; AI Worker is the underlying shared standard concept.** The component diagram also maps Grok Bot to AI Worker. These are concept mappings, not vendor certification or proof of interoperability. The other diagrams use Teloa AI employees as an example, retaining product role names while showing Worker instances, Team contracts and Org governance. A diagram does not establish that a product has deployed the illustrated structure. See the [mapping guide](../docs/mappings.md) for adaptation checks and sources.

Each language directory contains an editable SVG and a 2× PNG for each diagram. The SVG is the visual source; the Mermaid file is a compact textual outline. Normative requirements are defined by the [core specification](../spec/core.zh-CN.md) and [work profile](../spec/work-profile.zh-CN.md).

## 图示文件

每张图均提供可编辑 SVG 和 2 倍分辨率 PNG；同名 Mermaid 文件用于简要表达节点与关系。图示帮助阅读，具体要求以核心规范和工作与协作应用规范为准。

**AI 员工是 Teloa 的产品概念，AI Worker 是背后的通用标准概念。** 组成图同时说明 Grok Bot 与 AI Worker 的概念对应；这不表示厂商认证或已实现互操作。其余三图以 Teloa 为例，保留 AI 员工岗位名称，并展示 Worker 实例、Team 合同和 Org 治理。组成示意不代表产品已经部署该结构；适配核对项与来源见[映射文档](../docs/mappings.md)。
